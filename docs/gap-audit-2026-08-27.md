# Jowen Framework 全模块差距审计报告

> 审计日期：2026-08-27
> 基准：各模块 `README.md` + 根 `README.md` §8 设计 vs `src/main/java` 实际代码
> 方式：10 个并行子代理逐模块核对（cache 模块由主代理自查）；仅审计，未改动。

## 一、总览

| 模块                         | 类结构完整度 | 主要缺口                                                |
|------------------------------|--------------|---------------------------------------------------------|
| framework-core               | ★★★★☆   | 命名偏差、无包级 `@NullMarked`                          |
| framework-logger             | ★★★★☆   | 缺 `LoggerRuntimeHints`                                 |
| framework-data-core          | ★★★★☆   | 缺 `Isolation`/`Propagation`、`sort/` 包偏差            |
| framework-data-jdbc          | ★★★★☆   | 共性适配全缺（Jackson3/Micrometer/AOT）                 |
| framework-data-mybatis       | ★★★★☆   | 缺 `FlexAuditHandler`、共性适配全缺                     |
| framework-cache              | ★★★★☆   | 与模块 README 对齐；共性适配缺                          |
| framework-i18n               | ★★★☆☆   | Redis 组件、AOT/Micrometer、属性字段不全                |
| framework-plugin             | ★★★★☆   | 缺 YAML 解析、Actuator 端点、装配覆盖不全               |
| framework-extras             | ★★★★★   | 12 能力几乎全落地，仅 notification/operatelog 各缺实现  |
| framework-boot-autoconfigure | ★★★☆☆   | 缺 2 装配类、`@Import` 不一致、空壳类、starter POM 偏差 |

## 二、各模块明细

### framework-core

- 偏差：`Event`→`FrameworkEvent`；额外 5 类（`SPIImplementation`/`InitializingBean`/`DisposableBean`/`ObjectUtils`/`EventBus`）
- `@NullMarked` 为类级标注（35/35 类），无 `package-info.java`，与"包级"设计不符
- Javadoc/`@author`/`@since` 覆盖 100%

### framework-logger

- 6 子包与设计一一对应，命名无偏差
- **缺 `LoggerRuntimeHints`**（全库不存在）
- 同缺包级 `package-info.java`

### framework-data-core

- 缺 `transaction/Isolation`、`transaction/Propagation`
- 偏差：`Sort` 落在 `page/` 包（设计 `sort/`），`Order/Direction` 为 Sort 内部类而非顶级类
- 额外：`meta/` 子包（Table/Id/Column/GeneratedValue）、`EntityMetadataResolver`、`DataException`
- 零 Spring/JDBC 依赖，接口援引 `java.sql`/`javax.sql` 为 JDK 自带

### framework-data-jdbc

- 类结构基本齐备；README 设计树 `BeanRowMapper` 与实际 `BeanPropertyRowMapper` 不一致（README 树自相矛盾，以实际为准）
- 共性适配全缺：未用 Jackson 3、`PerformanceInterceptor` 未接 Micrometer、无 `JdbcRuntimeHints`、虚拟线程池参数无配置
- 额外：`DefaultEntityMetadata`/`DefaultIdGenerator`/`IdGenerators`/`TenantContext`/`context/` 包

### framework-data-mybatis

- **缺 `FlexAuditHandler`**（README 宣称的 Jackson3 审计落库无实现）
- 全部共性适配未落地：无 `MybatisRuntimeHints`、无 Jackson 3、无 Micrometer

### framework-cache（已重构，与模块 README 对齐）

- 模块级设计树全部落地
- 跨模块缺口：`JacksonSerializer` 仍用 `com.fasterxml`（Jackson 2）；无 `CacheStatsReporter`/`CacheHealthIndicator`
- 根 README §8.6 明显过时：@CacheInvalidate/@Caching、ConcurrentMapCache、CacheSyncBroadcaster、ProtobufCacheSerializer、防三盾、CacheType 均为旧设计

### framework-i18n

- 缺：`RedisMessageSource`、`RedisSubscriptionWatcher`（README 标注延后）
- 缺：`I18nRuntimeHints`、`I18nMetricsCollector`（零 Micrometer 引用）
- 属性模型不全：`SourceType` 缺 `REDIS/COMPOSITE`；`I18nProperties` 缺 context-mode/supported-locales/composite-order/cache-seconds/database/reload.strategy
- ScopedValue 已通过 core `ContextCarrier` 落地，但与 `LocaleContextHolder`(ThreadLocal) 并存未统一
- 位置偏差：`I18nAutoConfiguration` 实际在 boot 模块；装配属性类名为 `BootI18nProperties`

### framework-plugin

- 缺：`PluginYamlDescriptorParser`（SnakeYAML 已声明未实现）
- 缺：`PluginHealthIndicator`/`PluginEndpoint`（`/actuator/plugins` 无实现）
- HotSwapStrategy 仅 Restart 一种实现（缺 RELOAD_CLASSES/MANUAL）
- **`PluginAutoConfiguration` 只装配 `PluginLifecycleManager`**，PoolManager/Registry/DependencyResolver/HotSwapManager 均未接线
- 根 README `@ExtensionPoint` 表述过时（实际复用 core `@SPI`，符合模块决议）
- pom 缺设计 §七 的 `spring-boot-autoconfigure`/`spring-boot-configuration-processor`

### framework-extras

- lock/ratelimit/idempotent/storage/excel/captcha/ip2region/desensitize/datapermission/config 全部落地
- `framework.extras.<feature>.enabled` 开关齐备
- 仅缺：notification 的 `SimpleTemplateEngine`/`FreeMarkerTemplateEngine`（只有接口）；operatelog 的 `DatabaseOperateLogHandler`/`MqOperateLogHandler`（只有 `LoggingOperateLogHandler`）

### framework-boot-autoconfigure

- 缺：`ObservabilityAutoConfiguration`、`DataSourceAutoConfiguration`
- **`JowenAutoConfiguration` 的 `@Import` 未含 `PluginAutoConfiguration`**（但 imports 文件里注册了，二者不一致）
- `WebAutoConfiguration`、`EventBridgeAutoConfiguration` 为空壳类（无 `@AutoConfiguration`），未注册未导入
- `HealthAutoConfiguration` 缺 `@ConditionalOnProperty`
- 命名：`BootAutoConfiguration`→`JowenAutoConfiguration`、`DataJdbc`→`Jdbc`、`BootRuntimeHints`→`JowenRuntimeHints`

### 聚合 POM

- `framework-bom`：纯 POM、职责正确
- `framework-boot-starter`：`packaging=jar`（设计为纯 POM），缺 `framework-core`/`framework-logger` 直接依赖声明
- `framework-boot`：仅聚合 boot 两子模块，与 §8.13"聚合全部子模块"表述不符（实际聚合在根 pom）

## 三、跨模块共性缺口（按优先级）

1. **GraalVM AOT RuntimeHints**（M6）：仅 `JowenRuntimeHints` 单一实现，logger/jdbc/mybatis/cache/i18n 均无各自 registrar
2. **Jackson 3（`tools.jackson`）迁移**：所有模块仍用 `com.fasterxml`，零迁移
3. **Micrometer 2.0 指标**：cache/i18n/jdbc/logger 统计上报均未接入
4. **包级 `@NullMarked`**：全框架无 `package-info.java`，统一为类级标注
5. **根 README 过时**：§8.6（cache）、§8.8（plugin `@ExtensionPoint`）、§8.13（boot 聚合）表述与代码不符

## 四、建议排期

- **P0 框架正确性**：`JowenAutoConfiguration` 补 `@Import(PluginAutoConfiguration)`；`WebAutoConfiguration`/`EventBridgeAutoConfiguration` 补 `@AutoConfiguration` 或删除；starter 改回 POM 并补 core/logger 直连
- **P0 M6 云原生**：逐模块补 `RuntimeHintsRegistrar`、统一 Jackson 3 封装、Micrometer 指标
- **P1 模块补齐**：data-core `Isolation`/`Propagation` + `sort/` 包修正；mybatis `FlexAuditHandler`；i18n 属性模型补全；plugin YAML 解析 + Actuator 端点 + HotSwap 策略
- **P2 文档**：根 README §8.6/8.8/8.13 与代码对齐；`@NullMarked` 包级化

- [x] **P0-2a GraalVM RuntimeHints**：按领域拆分为 6 个 registrar（`Spi/Jdbc/Mybatis/Cache/I18n/Logger`），集中注册于 boot-autoconfigure `runtime/` 包，aot.factories 全部登记，删除旧 `JowenRuntimeHints`；i18n 资源模式补全 `messages*.properties`/`i18n/**/*.properties`
- [x] **P0-2b Jackson 3 迁移**：全库仅 `framework-cache/JacksonSerializer` 残留 Jackson 2，已迁移至 `tools.jackson.databind.json.JsonMapper`；cache 的 jackson-databind 坐标切换为 `tools.jackson.core`；boot-autoconfigure 清理 2 条冗余 `com.fasterxml` 依赖（extras 此前已迁移，为样板）
